## Практическая работа 4

### Порядок выполнения практической работы
1. Наберите и выполните приведенные выше на листингах программы, изучите их работу, протестируйте работу программ.
2. Попробуйте изменить ход выполнения программы с помощью  системных вызовов и управляющих конструкций языка `С`.
3. Напишите программу, в которой создаются два процесса родительский и дочерний с помощью `fork()`. Оформите создание процессов в виде вызова функции в `main()`.
Примеры прототипов функций:
```
void  ChildProcess(void); /* child process prototype  */
void  ParentProcess(void); /* parent process prototype */
```
В каждой функции организуется итерационный цикл, максимальное значение счетчика `MAX_COUNT 200` задайте через `define`. Каждый процесс в цикле печатает значение счетчика: 
```
printf("This line is from child, value = %d\n", i);
```
Изучите работу программы и измените её поведение с использованием изученных системных вызовов.
